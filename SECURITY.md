# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.2.x | Yes |
| < 0.2 | No |

## Reporting a vulnerability

Please report security issues privately to **security@elementeditor.dev**. Do not open a public issue or discussion.

Include the affected package and version, steps to reproduce, and the impact you expect. We will acknowledge the report, keep you updated while we work on a fix, and credit you in the release notes unless you prefer otherwise.
